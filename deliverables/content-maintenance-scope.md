# DEYA content maintenance scope

The unified admin maintains the existing homepage navigation, three supplied Banner text groups and homepage SEO. Customer-supplied Banner images, layout, responsive focal points, products, certificates and other page modules retain their dedicated data sources and fixed visual implementation. The adapter does not provide free-form layout or arbitrary CSS.

Public pages consume the published snapshot with a 60-second cache. Preview uses the one-time server exchange, disables public caching, analytics and indexing, and exposes an explicit exit action.
